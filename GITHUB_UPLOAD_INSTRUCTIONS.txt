STEP-BY-STEP POWERSHELL COMMANDS:
================================================================================

Open PowerShell, navigate to the project directory, and execute the following
commands in sequence:

# Step 1: Navigate to the project root
cd "C:\Users\Acer\LABEL SENTINEL"

# Step 2: Initialize local Git repository
git init

# Step 3: Stage all project files (governed by .gitignore)
git add .

# Step 4: Verify staged files (ensure no node_modules or .env files are staged)
git status

# Step 5: Create the initial commit
git commit -m "feat: complete Label Sentinel Week 2 frontend with live scanning, OCR, and regulatory compliance rules"

# Step 6: Rename default branch to main
git branch -M main

# Step 7: Connect your GitHub remote repository
# Replace <your-username> and <your-repo-name> with your actual GitHub details:
git remote add origin https://github.com/<your-username>/<your-repo-name>.git

# Step 8: Push your repository to GitHub
git push -u origin main
